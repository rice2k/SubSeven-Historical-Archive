# Research gaps and next targets

This archive deliberately labels gaps instead of treating repeated secondary claims as settled fact.

## Release / package research

- Recover primary change logs and original READMEs for each 1.x point release.
- Map exact package contents for 1.0–1.9 without inferring filenames from later releases.
- Build SHA-256/MD5 provenance records from trusted published catalogs where available without redistributing classic binaries.
- Separate original-author material, Sub7 Crew community material, later Legends revival material, the 2010 2.3 continuation and the modern Legacy remake.
- Verify the exact chronology, authorship and original project/site context of 2.3 from primary 2009–2010 snapshots.
