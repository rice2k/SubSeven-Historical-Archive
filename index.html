Background

What SubSeven was

Windows remote-access trojan

SubSeven, commonly shortened to Sub7, became one of the most recognizable Windows remote-access trojan families of the late 1990s and early 2000s. Its history is tied to the period when IRC, ICQ, AOL/AIM, personal websites, file-sharing, email attachments, and dial-up/home Windows systems were central to online culture.

Controller / server model

Historical packages separated the operator-facing controller/client from a remote server component. Builder/configuration programs such as EditServer were used to configure the server package. Later releases also documented auxiliary utilities and plugin-style extensions.

Delphi / Object Pascal

The classic family is associated with Borland Delphi/Object Pascal and Windows GUI development. Surviving source records and the modern Legacy recreation reinforce the Delphi lineage. The archive distinguishes classic code provenance from the later Legacy rewrite.

Social-engineering context

Its real-world impact did not depend only on software features. Historical infections were often associated with users being persuaded to execute disguised or renamed attachments/downloads. This archive describes those patterns at a defensive historical level without providing a deployment playbook.

Application family

How the package was organized

Controller / Client

classic

The operator-facing Windows GUI. Exact executable naming changed; SubSeven 2.2 is documented as sub7.exe, while Legends-era material names SubSeven.exe.

Server component

classic

The remotely installed component is historically called the server. Confirmed later packages name server.exe. This archive does not provide executable payloads.

EditServer

classic

EditServer.exe is documented for 2.0, 2.2, Legends and 2.3-era material as the configuration/builder-side application associated with the server component.

SIN

2.2

sin.exe is identified in 2.2 records as a Static IP Notifier utility. It is cataloged as part of the historical package, not distributed.

Plugins / DLLs

extensions

Period 2.2 documentation describes a plugin-oriented DLL design. The complete original distributed plugin-DLL name list remains a research target.

ICQMAPI.dll

Legends

Surviving Legends-era package documentation names ICQMAPI.dll as an ICQ integration/support library.
