Background

What SubSeven was

Windows remote-access trojan

SubSeven, usually shortened to Sub7, became one of the best-known Windows remote-access trojan families of the late 1990s and early 2000s. Its history overlaps the Windows 95/98/ME and NT/2000 era, dial-up Internet, AOL/AIM, ICQ, IRC, email attachments, early webcams, file-sharing and personal websites.

Controller / server model

Historical packages separated an operator-facing controller/client from a remote server component. Later packages used EditServer as a dedicated configuration/editor application, while auxiliary utilities and DLL/plugin concepts appeared in later branches.

Delphi / Object Pascal

The classic family is historically associated with Borland Delphi/Object Pascal and the Windows VCL ecosystem. Source-provenance material and the modern Legacy recreation preserve that Delphi lineage.

Why it became famous

The controller mixed serious file, credential, surveillance and remote-execution categories with visible prank functions. That combination made Sub7 memorable as a “hacker toy” while also making unauthorized installations a serious security/privacy threat.

Feature encyclopedia

What the major controls did

File Manager

Remote drive/directory/file browsing and normal management operations. One of the most persistent core feature families.

System Information

Displayed remote Windows/user/platform, directory, display, processor/storage and other system-environment information.

Process / Window management

Enumerated processes, applications and windows and exposed remote-management controls affecting them.

Screen / Desktop

Captured/viewed the remote desktop and exposed UI/display-manipulation categories.

Keylogger / Clipboard

Monitored typing and clipboard data. Historically important because of the privacy/credential risk.

Password / account-data categories

Classic releases included password/account-information recovery categories, a major reason SubSeven is studied as credential-stealing malware.

Registry Manager

Remote Windows Registry management; confirmed by at least the 1.4 generation in surviving catalogs.

Webcam / Audio

Later classic releases exposed webcam capture and audio/voice surveillance categories; webcam capture is confirmed by at least 1.8.

Network / Redirect / Proxy

Mature branches exposed network-management and relay/redirection concepts. Contemporary 2.2 reporting emphasized broader proxy/network-observation functionality.

IRC / ICQ / IM ecosystem

SubSeven’s history is tightly tied to IRC and ICQ notification/control culture and later instant-messaging observation categories.

Chat / Messages / Speech

Visible interaction features such as chat, pop-up messages and text-to-speech contributed to Sub7’s “hacker toy” reputation.

Prank / Fun controls

CD-tray, mouse, desktop/window, display and audio effects lived beside the serious surveillance and remote-control functions.

Programming and source provenance

Delphi, classic source and modern Legacy

Classic implementation

SubSeven is historically associated with Borland Delphi/Object Pascal and the VCL ecosystem. Useful development artifacts include .pas, .dpr, .dfm, compiled resources and Delphi component/library dependencies.

illwill/Sub7

The public GitLab repository at gitlab.com/illwill/sub7 is an important classic-source provenance record. A preserved capture labels it “Source code for SubSeven 2.1.3,” while the visible README discusses 2.1.2-era source received directly from mobman.

BSidesCT 2023

The official BSidesCT 2023 archive lists illwill’s “Finding mobman” talk on 30 September 2023 and describes acquisition of Sub7 2.1.3’s source code.

BSidesCT archive

Modern Legacy

DarkCoderSc/SubSeven is the official modern Delphi recreation. Its README states that malicious functions are omitted and documents benign File Manager, Process Manager, Remote Terminal and Windows Session Manager features.
